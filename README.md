# Internship Final Project Submission

This repository contains the complete source code, documentation, and supporting deliverables for both projects developed during my internship.

## Projects Overview

### FS-01: SyncSpace – Collaborative Workspace Platform

SyncSpace is a collaborative workspace application designed to help teams organize work, manage documents, and collaborate in real time.

**Key Features**
- User authentication and authorization
- Workspace creation and membership management
- Collaborative document editing
- Real-time synchronization
- Comments and document version history
- Role-based access control

**Technology Stack**
- Frontend: Next.js, React, TypeScript
- Backend: Node.js
- Database: PostgreSQL (Neon)
- ORM: Prisma
- Real-time collaboration: WebSockets and Yjs
- Coordination: Redis (where configured)

**Project Location:** `./FS-01/`  
**Project Recording:** [Watch Video Demonstration](https://drive.google.com/file/d/1JNU8kEirZYHpnLJ0bLCUTKMjrdpT46jx/view?usp=sharing)

### FS-02: Multi-Vendor E-Commerce Marketplace

A full-stack e-commerce platform that enables multiple vendors to manage their stores and sell products through a shared marketplace.

**Key Features**
- Customer, vendor, and admin roles
- Authentication and authorization
- Product and inventory management
- Shopping cart and checkout
- Payment gateway integration
- Order management and tracking
- Product search and filtering
- Vendor dashboard and administration

**Technology Stack**
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Caching: Redis
- Search: Elasticsearch
- Payments: Razorpay (if implemented)

**Project Location:** `./FS-02/`  
**Project Recording:** [Watch Video Demonstration](https://drive.google.com/file/d/1mhoCZli1xydNNX8OuYQzsFvH2bMyvbAA/view?usp=sharing)

## Installation and Setup

Each project has its own dependencies, environment variables, and setup instructions.

1. Clone the repository.
2. Open the required project folder (`FS-01` or `FS-02`).
3. Follow the installation instructions in that project's README.
4. Configure the required environment variables using the provided `.env.example` files.
5. Install dependencies and start the frontend and backend services.
